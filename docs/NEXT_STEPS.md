# Порядок модулей

Источник правды по продукту — карта продукта (focus-product-map).
Работаем строго по порядку, один модуль = один PR-цикл.

## Сделано
- Auth (email/пароль, подтверждение почты), middleware-гейт
- Spaces + membership, RLS по членству
- Задачи: быстрый ввод, полная форма, карточка (чеклист, ссылки,
  комментарии, пикер диапазона начало–конец)
- Кастомные статусы, проекты (база)
- Воркспейс Деск/Фокус/План (переключение уровней), недельный планировщик
- Схема-спутники: time_entries, activity_log, task_assignees

## Очередь
1. ✅ ТЗ №1 — фиксация версий, актуализация docs (этот документ)
2. Этапы проектов (project_stages) + полная страница Проектов
   (карточка: сроки, описание, статус, сумма; список + таймлайн)
3. Выдача дня в Фокусе: слотовые по времени, бесслотовые по скорингу
   (просрочка → приоритет → ближайший дедлайн → возраст)
4. Бэклог-панель (глобальная, задачи без дат, drag в План)
5. Чат-строка внизу всех экранов + NL-парсинг ввода в задачи
6. Клиенты (карточки, привязка к проектам) + Финансы (платежи:
   план/ждём/оплачен)
7. Журнал завершённых + Корзина (восстановление, автоочистка)
8. Дневник занятости (единая модель времени с таймером)
9. Деск: саммари + первые виджеты (фиксированный набор)
10. Аналитика: ключевые графики (фиксированный набор)

## Анти-цели (не делаем)
Гант с зависимостями · автоматизации workflow · роли сложнее
shared/hidden · геймификация · счета и банк-интеграции в v1 ·
конструкторы графиков/виджетов в v1

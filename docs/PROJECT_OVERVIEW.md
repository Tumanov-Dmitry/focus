# Фокус — Project Overview

Фокус — минималистичный AI-first таск-трекер для спокойного планирования дня. MVP начинается с узкого центрального интерфейса, коротких списков задач и AI-строки для быстрого ввода.

## Цели MVP

- Быстро фиксировать задачи естественным языком.
- Показывать только актуальный контекст дня.
- Избежать тяжёлого dashboard-вида и визуального шума.
- Подготовить фундамент для Supabase Auth, PostgreSQL и AI-интеграций.

# Design System

Визуальный язык: тёплый минимализм, editorial/productivity типографика, много воздуха и тонкие тёплые границы.

## Токены

- `background`: тёплый почти белый.
- `foreground`: глубокий почти чёрный.
- `muted`: мягкий серо-бежевый.
- `border`: тонкий тёплый серый.
- `primary`: графитовый.
- `accent`: спокойный оливково-зелёный акцент.

CSS variables находятся в `app/globals.css`, Tailwind-маппинг — в `tailwind.config.ts`.
